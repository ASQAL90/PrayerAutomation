Offline locality data (schema v2)
=================================

This application includes derived subsets of the GeoNames Gazetteer and the
Indonesian administrative register, used fully offline. No lookup request is
made when these datasets are used.

Source data
-----------
GeoNames (https://www.geonames.org/, CC BY 4.0):
- https://download.geonames.org/export/dump/cities500.zip
- https://download.geonames.org/export/dump/ID.zip
- https://download.geonames.org/export/dump/admin1CodesASCII.txt
- https://download.geonames.org/export/dump/admin2Codes.txt
- https://download.geonames.org/export/dump/countryInfo.txt
- https://download.geonames.org/export/dump/alternateNamesV2.zip

Kemendagri administrative codes (cahyadsn/wilayah, MIT-licensed tooling):
- https://github.com/cahyadsn/wilayah
- Kepmendagri No. 300.2.2-2430 Tahun 2025
- Files used: db/wilayah.sql and db/wilayah_level_1_2.sql

Copernicus DEM elevation samples (Open-Meteo Elevation API, GLO-90, CC BY 4.0):
- https://open-meteo.com/en/docs/elevation-api
- https://registry.opendata.aws/copernicus-dem/

Snapshot: 2026-11-22 (UTC). File hashes are listed in data/offline-data-manifest.json
in the source repository.

Changes made
------------
- `cities500.tsv.gz`: feature-class P records from GeoNames cities500. Each row
  keeps the locality name, first-level administrative name, country name, WGS84
  latitude/longitude, ISO country code, GeoNames `dem`, sampled elevation,
  feature code, population, alternate names, elevation source, and elevation
  quality.
- `indonesia.tsv.gz`: feature-class P records for Indonesia. Regency and province
  names are taken from the official Kemendagri hierarchy where the GeoNames
  admin2 name could be matched (about 95.5% of rows); unmatched rows keep the
  GeoNames regency name. Sampled elevation is placed after `dem`; elevation
  source/quality columns record the provenance. Alternate names are used only
  as additional search keys and never rewrite a place's own name.
- `indonesia.boundary.bin`: derived from Natural Earth 1:10m Admin 0 Countries,
  Indonesia feature (public domain). Only exterior rings are kept. The file is
  used to choose between the Indonesian and global layers; it is not a legal,
  cadastral, or navigational boundary.
