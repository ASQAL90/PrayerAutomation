GeoNames offline locality data

This application includes derived subsets of the GeoNames Gazetteer, used fully
offline. No lookup request is made when these datasets are used.

Source data:
- https://download.geonames.org/export/dump/cities1000.zip
- https://download.geonames.org/export/dump/ID.zip
- https://download.geonames.org/export/dump/admin1CodesASCII.txt
- https://download.geonames.org/export/dump/admin2Codes.txt
- https://download.geonames.org/export/dump/countryInfo.txt
- https://www.geonames.org/

Snapshot: source files last modified 2026-11-19 (UTC); downloaded 2026-11-19.

Changes made:
- `cities1000.tsv.gz`: retained GeoNames feature-class P (populated-place)
  records; selected the locality name, English ASCII first-level administrative
  name, country name, WGS84 latitude/longitude, ISO country code, and the
  GeoNames `dem` elevation in metres.
- `indonesia.tsv.gz`: retained feature-class P records for Indonesia; added the
  second-level administrative name (regency/city) and replaced the English
  first-level name with the official Indonesian province name. Province names
  are derived from the GeoNames admin1 codes plus the four Papua provinces added
  in 2022; nine English regency names were normalised to Indonesian.
- Whitespace normalised and the results compressed as tab-separated files.

Indonesia boundary:
- `indonesia.boundary.bin` is derived from Natural Earth 1:10m Admin 0
  Countries, Indonesia feature (public domain).
- https://www.naturalearthdata.com/
- https://github.com/nvkelso/natural-earth-vector
- Only exterior rings are kept and stored in a compact binary form. The file is
  used to choose between the detailed Indonesian layer and the global layer; it
  is not a legal, cadastral, or navigational boundary.
