GeoNames offline locality data

This application includes a derived subset of the GeoNames Gazetteer `cities1000` extract.

Source data:
- https://download.geonames.org/export/dump/cities1000.zip
- https://download.geonames.org/export/dump/admin1CodesASCII.txt
- https://download.geonames.org/export/dump/countryInfo.txt
- https://www.geonames.org/

Snapshot: source files last modified 2026-11-19 (UTC); downloaded 2026-11-19.
Changes made: retained GeoNames feature-class P (populated-place) records; selected the locality name, English ASCII first-level administrative name, country name, WGS84 latitude/longitude, ISO country code, and the GeoNames `dem` elevation in metres; normalized whitespace and compressed the tab-separated result as `cities1000.tsv.gz`. No lookup request is made when this offline dataset is used.
