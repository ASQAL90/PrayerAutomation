Sebelum membuka aplikasi utama

Portable membaca profil lama di %APPDATA%\PrayerAutomation\config.json. Folder build baru tidak menonaktifkan auto-lock. Profil pada pemeriksaan ini memiliki opsi Windows aktif; aplikasi utama tidak dijalankan dalam suite.

Gunakan akun biasa di satu PC uji. Manifest diperiksa sebagai asInvoker dan uiAccess=false. Jika muncul UAC, batalkan; jangan elevate atau memasang helper. Baca checklist dan terima risiko profil sebelum membuka EXE.

03 · PERHITUNGAN LOKAL

Rust menghitung jadwal dan kalender

PrayerScheduleService memakai native prayer_core.dll, timezone dan koreksi lokal. Kalender Hijriyah/peringatan merupakan perkiraan, bukan pengumuman resmi.

Nama metode atau koreksi satu tanggal bukan bukti kesesuaian tahunan dengan jadwal resmi. Terbit dan Duha ditampilkan, tetapi tidak masuk jalur reminder, auto-lock atau gambar sementara.

Lokasi manual tidak diganti diam-diam. Lookup nama lokasi offline memakai GeoNames. Request online hanya setelah tindakan dan consent eksplisit yang dapat dicabut; posisi proxy/IP bukan bukti lokasi fisik.

Tiga jalur dengan efek berbeda

Pengingat teks

ReminderScheduler

  • Popup teks sebelum waktu sesuai pengaturan.
  • Tanpa suara atau adzan.
  • Timer memeriksa tiap 15 detik.
  • Tidak mengunci sesi.

Auto-lock sesi

AutoLockScheduler

  • Opt-in terpisah; default konfigurasi baru nonaktif.
  • Jalur native memanggil LockWorkStation.
  • Lima waktu wajib saja.
  • Pengguna membuka sesi lewat login Windows biasa.

Gambar lock screen

LockScreenImageScheduler

  • Consent tersimpan dan preflight diperlukan.
  • Snapshot + jurnal sebelum setter.
  • Restore setelah durasi tetap 60 menit; bukan deteksi selesai sholat.
  • Jalur ini tidak mengunci sesi dan tidak mengubah wallpaper desktop.
Lihat apply / restore dan batasnya

Marquee dan pesan offline

Widget menampilkan tanggal, jam/timezone, jadwal/countdown, konteks kalender dan satu pesan hadis per putaran. Koleksi aktif tetap lima ringkasan makna dengan nomor/URL sumber; riset kandidat tambahan tidak otomatis mengubah koleksi aplikasi.

Pengulangan teks diukur sebelum clipping agar baris dapat masuk kembali dari kanan. Bukti bitmap, timer dan rotasi tidak menggantikan acceptance wrap, font dan per-monitor DPI pengguna. Baca lingkup bukti yang benar-benar diperiksa.

Hide bukan Exit; Exit dapat menunggu recovery

Tombol X menyembunyikan jendela utama ke tray dan membuang preview. Perintah Keluar menghentikan jalur aktif, menunggu operasi in-flight, lalu meminta restore. Jika restore pending atau gagal, aplikasi dapat tetap hidup untuk retry. Force-close menghentikan kemampuan restore sampai app dijalankan kembali.

Jangan menghapus jurnal, merusak Registry, menjalankan helper atau elevate untuk mempercepat pemulihan. Override manual pengguna harus dihormati.
