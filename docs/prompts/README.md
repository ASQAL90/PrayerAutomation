# Prompt & spesifikasi proyek

Folder ini menyimpan dokumen sumber niat produk: instruksi kerja, PRD, dan dokumentasi program yang dipakai sebagai "prompt" saat mengembangkan Ayo Jama'ah!.

| Dokumen | Isi |
|---|---|
| [`PRD.md`](PRD.md) | Product requirements awal: tujuan, cakupan fitur, dan batasan teknis. |
| [`PROGRAM_DOCUMENTATION_ID.md`](PROGRAM_DOCUMENTATION_ID.md) | Dokumentasi program lengkap berbahasa Indonesia: alur fitur, konfigurasi, dan catatan implementasi. |

## Catatan

- Kedua dokumen ini **historis/rujukan**, bukan instruksi rilis terbaru. Status fitur dan nomor versi di dalamnya bisa tertinggal dari kode.
- Untuk status terkini pakai [`../README.md`](../README.md) (indeks dokumentasi) dan [`../../README.md`](../../README.md) (README aplikasi).
- Catatan progres per tanggal ada di [`../progress/`](../progress/).
- Path di dalam dokumen sudah disesuaikan dengan struktur baru (`src/PrayerAutomation.UI`, `src/rust-core`, `dist/`).
