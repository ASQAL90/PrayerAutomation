## Perbaikan

- Ukuran paket self-contained diperkecil lewat optimasi Tier 1: berkas runtime/framework yang tidak diperlukan aplikasi dipangkas dari payload publish, sementara berkas wajib tetap diverifikasi. `deps.json` dibersihkan dan dipetakan ulang agar tidak menunjuk berkas yang dihapus atau path paket yang ter-flatten.
- Dependensi WinForms dihapus lewat optimasi Tier 2: tray icon dipindahkan ke implementasi native `Shell_NotifyIconW` dengan menu konteks WPF, sehingga `UseWindowsForms` tidak lagi diperlukan.
- Menu systray kini memakai template tema aplikasi (latar, teks, hover, dan separator) agar tetap kontras dan konsisten pada tema terang maupun gelap.

## Penambahan

- Installer NSIS kini tersedia dalam tiga varian: universal (`x64+x86`, default), `x64`, dan `x86`. Updater memprioritaskan installer sesuai arsitektur sistem dengan fallback ke installer universal.

## Catatan

- Aplikasi tetap self-contained; pengguna tidak perlu memasang .NET Runtime terpisah.
- Rilis `v2.5.1` dibangun oleh workflow `Release` dari tag `v2.5.1`.
