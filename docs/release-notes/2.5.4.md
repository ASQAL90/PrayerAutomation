## Perbaikan

- Jendela "Riwayat perubahan" tidak lagi memotong setiap baris pada 220 karakter.
- Teks Markdown seperti tanda bintang dan backtick dibersihkan sebelum ditampilkan, sehingga kalimat lebih mudah dibaca.
- Panel pratinjau catatan rilis pada popup pembaruan juga tidak lagi memotong bullet panjang; batas item dinaikkan menjadi 1200 karakter dengan total 20.000 karakter.
- Catatan rilis 2.5.2 dan 2.5.3 sudah dipecah menjadi satu gagasan per baris agar tidak ada kalimat yang terpotong.

## Fitur baru

- Tidak ada fitur baru di rilis ini; perubahan hanya pada tampilan riwayat perubahan dan kerapian catatan rilis.

## Catatan

- Rilis ini menyusul `v2.5.3`; tag `v2.5.3` dibuat sebelum perbaikan tampilan ini masuk, sehingga paket `v2.5.4` adalah rilis pertama yang memuatnya.
- Perbaikan `v2.5.2` tetap termasuk: nomor versi tunggal, `/UPDATEMODE` utuh, penolakan `/D=`, dan pilihan simpan/hapus data saat uninstall.
- Perbaikan `v2.5.3` tetap termasuk: batas respons pembaruan, parser waktu-linear, dan resolver `prayer_core` dari folder aplikasi.
- Aplikasi tetap self-contained; pengguna tidak perlu memasang .NET Runtime terpisah.
- Rilis `v2.5.4` dibangun oleh workflow `Release` dari tag `v2.5.4` dengan catatan rilis ini sebagai body. Kunci dan public key penandatanganan pembaruan tidak berubah.
- Uji runtime Windows untuk resolver native, smoke install/upgrade/uninstall, `/UPDATEMODE` versus `/D=`/`/NCRC`, dan verifikasi visual halaman uninstall masih perlu dijalankan pada PC pengguna.
