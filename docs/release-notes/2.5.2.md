## Perbaikan

- Nomor versi kini hanya punya satu sumber: `<Version>` di `src/PrayerAutomation.UI/PrayerAutomation.UI.csproj`. `installer/build_installer_nsis.py` membacanya untuk nama berkas keluaran dan meneruskannya ke NSIS sebagai `-DAPP_VERSION`/`-DAPP_VERSION_QUAD`. `installer/nsis/AyoJamaah.nsi` tidak lagi menyimpan nomor versi sendiri, dan `makensis` yang dijalankan langsung tanpa define tersebut berhenti dengan pesan yang jelas alih-alih mengemas versi lama.
- Argumen installer diperketat. `/UPDATEMODE` hanya dikenali bila berdiri sendiri sebagai satu argumen, sehingga potongan teks di path atau opsi lain tidak bisa mengaktifkan mode pembaruan senyap dan melewati konfirmasi. `/D=` ditolak sebelum halaman pertama karena NSIS menerapkannya setelah `.onInit`, di luar target per-user dan pemeriksaan boundary yang sudah dijalankan.

## Fitur baru

- Uninstaller menanyakan apakah pengaturan dan data pengguna disimpan atau dihapus semuanya. **Simpan pengaturan dan data saya** adalah pilihan awal; **Hapus semua pengaturan dan data Ayo Jama'ah!** menghapus folder profil aplikasi, termasuk log dan unduhan pembaruan. Jurnal pemulihan lock screen tidak pernah dihapus, dan guard yang sudah ada membatalkan uninstall selama pemulihan masih tertunda.

## Catatan

- Aplikasi tetap self-contained; pengguna tidak perlu memasang .NET Runtime terpisah.
- Rilis `v2.5.2` dibangun oleh workflow `Release` dari tag `v2.5.2` dengan catatan rilis ini sebagai body.
- Pilihan hapus data pada uninstall hanya berjalan pada uninstall interaktif; mode senyap tetap ditolak.
- Uji install/upgrade/uninstall dan verifikasi visual halaman uninstall baru harus dijalankan di Windows.
