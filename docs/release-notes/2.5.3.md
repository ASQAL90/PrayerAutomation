## Perbaikan

- Pemuatan `prayer_core` sekarang memakai resolver P/Invoke yang dipasang sebelum panggilan native pertama. Hanya `prayer_core.dll`, `libprayer_core.so`, atau `libprayer_core.dylib` tepat di folder aplikasi yang diterima; berkas kosong, symlink/junction, dan path di luar folder aplikasi ditolak dengan `DllNotFoundException`. Tidak ada fallback ke pencarian pustaka bawaan yang bisa memuat berkas dari lokasi lain.
- Respons pembaruan dibatasi sebelum diverifikasi: JSON rilis maksimum 1 MiB, manifest bertanda tangan 512 KiB, dan tanda tangan 16 KiB. Batas diperiksa dari `Content-Length` dan ditegakkan lagi saat streaming, sehingga endpoint yang rusak atau jahat tidak menghabiskan memori sebelum digest dan tanda tangan diperiksa.
- Parser catatan rilis memakai `RegexOptions.NonBacktracking` dengan body dibatasi 64 KiB, sehingga teks catatan rilis yang aneh tidak memicu backtracking eksponensial.
- Nama aset pembaruan divalidasi sebagai nama berkas polos dan manifest bertanda tangan dengan nama aset berbahaya ditolak; untuk rilis 2.4.0 ke atas pembaruan dibatalkan bila manifest atau tanda tangan gagal diverifikasi, tanpa fallback ke aset unsigned.

## Fitur baru

- Tidak ada fitur baru di rilis ini; seluruh perubahan bersifat pengerasan pembaruan dan pemuatan native.

## Catatan

- Rilis ini menyusul `v2.5.2`; tag `v2.5.2` dibuat sebelum perbaikan di atas masuk, sehingga paket `v2.5.3` adalah rilis pertama yang memuat semuanya. Perbaikan nomor versi tunggal, argumen `/UPDATEMODE` utuh, penolakan `/D=`, dan pilihan simpan/hapus data saat uninstall dari `v2.5.2` tetap termasuk.
- Aplikasi tetap self-contained; pengguna tidak perlu memasang .NET Runtime terpisah.
- Rilis `v2.5.3` dibangun oleh workflow `Release` dari tag `v2.5.3` dengan catatan rilis ini sebagai body. Kunci dan public key penandatanganan pembaruan tidak berubah.
- Uji runtime Windows untuk resolver native, smoke install/upgrade/uninstall, `/UPDATEMODE` versus `/D=`/`/NCRC`, dan verifikasi visual halaman uninstall masih perlu dijalankan pada PC pengguna.
