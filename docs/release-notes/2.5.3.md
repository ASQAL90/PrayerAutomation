## Perbaikan

- Pemuatan `prayer_core` sekarang memakai resolver P/Invoke yang dipasang sebelum panggilan native pertama.
- Hanya `prayer_core.dll`, `libprayer_core.so`, atau `libprayer_core.dylib` tepat di folder aplikasi yang diterima.
- Berkas kosong, symlink/junction, dan path di luar folder aplikasi ditolak dengan `DllNotFoundException`.
- Tidak ada fallback ke pencarian pustaka bawaan yang bisa memuat berkas dari lokasi lain.
- Respons pembaruan dibatasi sebelum diverifikasi: JSON rilis maksimum 1 MiB, manifest 512 KiB, dan tanda tangan 16 KiB.
- Batas diperiksa dari `Content-Length` dan ditegakkan lagi saat streaming.
- Endpoint yang rusak atau jahat tidak bisa menghabiskan memori sebelum digest dan tanda tangan diperiksa.
- Parser catatan rilis memakai `RegexOptions.NonBacktracking` dengan body dibatasi 64 KiB.
- Catatan rilis yang aneh tidak memicu backtracking eksponensial.
- Nama aset pembaruan divalidasi sebagai nama berkas polos dan manifest dengan nama berbahaya ditolak.
- Untuk rilis 2.4.0 ke atas, pembaruan dibatalkan bila manifest atau tanda tangan gagal diverifikasi, tanpa fallback ke aset unsigned.
- Teks riwayat perubahan tidak lagi dipotong pada batas 220 karakter di jendela About maupun panel pembaruan.

## Fitur baru

- Tidak ada fitur baru di rilis ini; seluruh perubahan bersifat pengerasan pembaruan dan pemuatan native.

## Catatan

- Rilis ini menyusul `v2.5.2`; tag `v2.5.2` dibuat sebelum perbaikan di atas masuk.
- Paket `v2.5.3` adalah rilis pertama yang memuat seluruh perbaikan tersebut.
- Perbaikan v2.5.2 tetap termasuk: nomor versi tunggal, `/UPDATEMODE` utuh, penolakan `/D=`, dan pilihan simpan/hapus data saat uninstall.
- Aplikasi tetap self-contained; pengguna tidak perlu memasang .NET Runtime terpisah.
- Rilis `v2.5.3` dibangun oleh workflow `Release` dari tag `v2.5.3` dengan catatan rilis ini sebagai body.
- Kunci dan public key penandatanganan pembaruan tidak berubah.
- Uji runtime Windows untuk resolver native, smoke install/upgrade/uninstall, `/UPDATEMODE` versus `/D=`/`/NCRC`, dan verifikasi visual halaman uninstall masih perlu dijalankan pada PC pengguna.
